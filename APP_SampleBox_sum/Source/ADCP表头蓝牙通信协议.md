BLE设备与手机的通信协议
一、	通信过程
1、	建立联接后，手机需登录认证。
2、	认证完成后，发送消息加密才能做正常的通信。

二、	通信格式
正常通信格式（手机端加密前）：
字段	长度(字节)	内容
包头（Head）	2	0xAA 0xBB
长度（MsgLen）	2	16位短整型（总长度）
通信ID号	8	ASCII码
数据段长度（DataLen）	2	16位短整型
数据段（Data）	0 ~4096	ASCII
校验（CRC）	1	XOR，不含包头包尾
包尾（End）	2	0xEE x0xFF


BLE设备返回：
字段	长度(字节)	内容
包头（Head）	2	0xAA 0xBB
长度（MsgLen）	2	16位短整型（总长度）
通信ID号	8	ASCII码
数据段长度（DataLen）	2	16位短整型
数据段（Data）	0 ~4096	16进制
校验（CRC）	1	XOR，不含包头包尾
包尾（End）	2	0xEE x0xFF



新版协议兼容分包发送
字段	长度(字节)	内容
包头（Head）	2	0xAA 0xBB
长度（MsgLen）	2	16位短整型（总长度）
通信消息类型	4	ASCII码:LIHE-表示用新协议
分包号（NO）	2	16位整型，不拆包时为0
总包号（TNO）	2	16位整型，总包号大于0时表示拆包
数据段长度（DataLen）	2	16位短整型
数据段（Data）	0 ~4096	16进制
校验（CRC）	1	XOR，不含包头包尾
包尾（End）	2	0xEE x0xFF
三、	通信内容：
1 Write指令（写指令，返回相同的信息表示成功，否则表示失败）
	发送指令：
（1）	SysTime			系统时间（12位) yyMMddhhmmss 例260624235959
（2）	DevName		设备名（12位）
（3）	DevNum		设备唯一标识符（12位）
（4）	DevMN			设备所在断面MN号（12位）
（5）	DevIp      		编号#上传IP（12位）   例123456789123
（6）	DevPort			编号#上传端口（5位）  例12345
（7）	BleAddr			蓝牙地址（12位）
（8）	UsrName		操作账号名（最长24位）
（9）	RunMode 		运行模式 0：自动模式 1：手动模式 2：在线模式 3：维护模式
（10）	AutoTime	自动模式测试持续时间（5位）秒
（11）	ManualTime	手动模式测试持续时间（5位）秒
（12）	SamTime		在线模式采数间隔时间 （5位）秒
（13）	UpTime		在线模式上传间隔时间 （5位）秒   （传输周期）
（14）	SamWait		在线模式采样耗时（5位）秒
（15）	StartTime  首次测试时间（12位）yyMMddhhmmss 例260624235959
（16）	DevST		上传编号
（17）	LotPro		上传协议
（18）	Elevation		河底高程 单位mm
（19）	Install		安装高度 单位mm
（20）	Shape		断面形状-断面参数1-断面参数2-断面参数3
（21）	Coeff		曲线系数A-曲线系数B-曲线系数C
（22）	Positive		正向累计流量（浮点数）-正向累计流量进位次数（整数）
（23）	Reverse		反向累计流量（浮点数）-反向累计流量进位次数（整数）
（24）	AbsCumu	绝对值累计流量（浮点数）-绝对值累计流量进位次数（整数）
（25）	NetCumu	净累计流量（浮点数）-净累计流量进位次数（整数）
（26）	DelHistory   （删除历史数据） 第n页-第m个
（27）	Direction     安装方向设置 1-正向 -1表示反向


返回指令：返回指令为发送指令相同时，表示写成功；
Eg	发送：Write Vesion=1a3456
	返回：Write Vesion=1a3456

2 Read指令（Read  Detail 读指令）
发送指令：
（1）	系统时间（12位 210122235959）
（2）	固件版本 （6位）例如：230706
（3）	设备名	（12位）
（4）	设备唯一标识
（5）	设备所在断面MN号 （12位）
（6）	设备IP  例：036137024154  表示36.137.24.154
（7）	设备端口 (5位）
（8）	蓝牙地址 （12位）
（9）	设备状态（5位）  （见附录二）
（10）	操作账号名（24位）
（11）	设备电池电压 （5位，小数点后两位，电压（9.8 ~ 10.6）对应电量0~100
（12）	内存编号  （3位）
（13）	运行模式（3位）运行模式 0：自动模式 1：手动模式 2：在线模式 3：维护模式
（14）	自动测试模式持续时间（5位 ，单位秒）
（15）	手动模式持续时间（5位 ，单位秒）
（16）	在线模式采样间隔时间（5位 ，单位秒）
（17）	在线模式上传间隔时间（5位 ，单位秒）
（18）	在线模式下供电等待时间（5位 ，单位秒）
（19）	在线模式首次上传时间（260624210100）
（20）	212协议ST编号
（21）	上传协议 （0：212 ，1：MQTT）
（22）	SIM卡NCCID号 （20位）
（23）	SIM卡IMSI号 	（15位）
（24）	网络信号强度	（2位）
（25）	本地IP		(12位)
（26）	流速 （小数，位数不定,m/s）
（27）	原始流速（小数，位数不定，m/s）
（28）	瞬时流量（小数，位数不定,m3/s）
（29）	水深（小数，位数不定,m）
（30）	水位（小数，位数不定,m）
（31）	断面面积（小数，位数不定,m2）
（32）	水温（小数，位数不定,摄氏度）
（33）	横滚角（小数，位数不定，°）
（34）	俯仰角（小数，位数不定，°）
（35）	间隔流量
（36）	净累计流量
（37）	净累计流量进位次数
（38）	正向累计流量
（39）	正向累计流量进位次数
（40）	反向累计流量
（41）	反向累计流量进位次数
（42）	绝对值累计流量
（43）	绝对值累计流量进位次数
（44）	河底高程（位数不定,mm）
（45）	安装高度（小数，位数不定，m）
（46）	断面形状（0:矩形 1：梯形 2：V形 3：U形 4：圆形）
（47）	断面参数1（小数，位数不定，单位m）（详见附录一）
（48）	断面参数2（小数，位数不定，单位m）（详见附录一）
（49）	断面参数3（小数，位数不定，单位m）（详见附录一）
（50）	曲线系数A（小数，位数不定，单位m）
（51）	曲线系数B（小数，位数不定，单位m）
（52）	曲线系数C（小数，位数不定，单位m）
Read History=n   //读取历史数据,(n为读取的页)
下列数据均以”-”隔开，不同数据组以“#”隔开
（1）数据标识 （3位）（000：未上传数据 ，001：已上传数据）
（2）数据时间 （12位）例260521111109 代表2026年5月21日11点12分09秒
（3）MN号（12位）
（4）操作的蓝牙账号（24位）
（5）流速（小数，位数不定,m/s）
（6）瞬时流量（小数，位数不定,m3/s）
（7）水深（小数，位数不定,m）
（8）水位（小数，位数不定,m）
（9）过水面积（小数，位数不定,m2）
（10）水温（小数，位数不定,℃）
（11）俯仰角（小数，位数不定,°）
（12）横滚角（小数，位数不定，°）
（13）安装高度（小数，位数不定，m）
（14）河底高程（位数不定，mm）
（15）电源电压（小数，位数不定，V）

返回指令：返回相对应的查询信息
Eg 发送：Read Vesion
   返回：1a3456


3 Set指令（操作指令）
发送指令：
（1）	Set Start		手动测试模式下启动手动测试
（2）	Set Stop 		手动测试模式下停止手动测试
（3）	Set DelHistory 	清空所有历史数据
（4）	Set DelUP		清空所有待上传数据
（5）	Set ZeroInit 	清空累计流量
（6）	Set SysInit		恢复出厂默认设置
（7）	Set SysReset	复位重启
（8）	Set NetReset 	复位初始化网络模块
（9）	Set Pressure  校准大气压
返回指令：返回指令为发送指令相同时，表示操作成功；
