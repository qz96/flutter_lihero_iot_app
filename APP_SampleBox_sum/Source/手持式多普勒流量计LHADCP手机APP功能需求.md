便携式多普勒流量计（LHADCP）手机APP开发设计需求
1	主界面
主界面为分：设备信息、常用功能两个区域，核心目标：快速连设备、直观看状态、一键进测量。
a) 	设备信息显示 ★
1)	电池信息：电量（百分比 + 图标）+ 60%低电红色告警提醒，重启开关
2)	设备固件版本号、平台连接网络信号强度、探头水温温度
3)	存储空间信息：可用空间量（GB）、已用空间量（GB）
4)	设备工况：设备名称、设备MN、设备状态、工作模式、运行模式、蓝牙信号强度
b) 	常用功能（快捷入口）★
点击入口：单点测量、历史数据、校准、参数设置、上传设置、多线多点测量。



数据来源：通过《ADCP表头蓝牙通信协议20260615》中Read Detail读取到设备信息并存储下来，其中包括主界面的基础信息（固件版本号、设备电池电压和转换成电量%、网络信号强度、探头水温温度、设备名称、设备MN号、设备状态、工作模式、运行模式）

2	单点测量 ★
可编辑设备当前的运行模式和相关运行规则信息、测量人员、断面MN、断面形状与相关参数信息，实时数据可读、可看。
2.1	运行模式
	选择自动模式时：
第一步、通过Write AutoTime=自动测试模式持续时间（默认显示上一次设置的自动测试模式持续时间），来修改自动测试模式持续时间；
第二步、点击开始测量Write RunMode =0；
第三步、写入Write RunMode =0返回成功后，按当前的自动测试模式持续时间，进行倒计时弹窗，不允许手动取消；
第四步、倒计时结束后弹窗自动消失，跳转到实时数据面板页面，通过读取Read Detail显示出水深、水温、流速、流量、过水面积等实时参数。
	选择手动模式时：
第一步、Write RunMode =1，返回成功表示切换到了手动模式，并显示开始测量（默认可点击）和结束测量按钮（默认不可点击）；
第二步、点击开始Set Start，返回成功后，进行秒级计时器控件显示（同时，开始按钮变成不可点击，结束按钮变成可以点击）；
第三步、用户点击结束测量Set Stop，返回成功后，跳转到实时数据面板页面，通过读取Read Detail显示出水深、水温、流速、流量、过水面积等实时参数。
	选择在线模式时：
第一步、通过Write SamWait =在线模式采样耗时（默认时间为上一次设置的在线模式采样耗时），来修改在线模式采样耗时；通过Write SamTime	=在线模式采数间隔时间（默认为上一次设置），分钟数（整数）默认转换为秒，来修改在线模式采数间隔时间；通过Write UpTime	=在线模式上传间隔时间（默认为上一次设置），分钟数（整数）默认转换为秒，来修改在线模式上传间隔时间；通过Write StartTime=首次测试时间（必选项，必须大于当前时间），来修改首次测试时间；如采样耗时100S，首次开始时间260624103059，周期时间60min,那么当时系统时间到达2026-06-24 10:30:59后开始首次测量，采样100S后，更新测量结果，当到下一个周期11:30:59后又开始进行一轮测量，如往复。
第二步，Write RunMode =2，返回成功表示切换到了在线模式；
第三步，如要停止在线模式的往复周期测量，则将测量模式改成手动或维护模式即可。
第四步，在线模式下，页面有一个“实时数据查看”的按钮，用于跳转到实时数据面板页面，查看最新的实时数据


	选择维护模式时：
通过Write RunMode =3，返回成功表示切换到了维护模式；

2.2	断面形状选择★
断面形状设置  通过Write Shape=断面形状-断面参数1-断面参数2-断面参数3，来设置形状和相应参数，参数与形状的对应关系依据《附录一:雷达流量计断面参数详解》
矩形渠：可设沟渠宽度
梯形渠：可设底边宽度及两角角度
V形渠：可设底角角度
U形渠：可设置弧形半径及弧形角度
圆形管道：可设置圆形管道管径

当前断面形状信息在Read Detail中有返回

2.3	其他3个设置参数：
在通信协议中有写入指令
（4）	DevMN			设备所在断面MN号（12位）
（8）	UsrName		操作账号名（最长24位）
淤积厚度：设置过水断面淤泥厚度用于对过水断面面积修正。（预留暂无数据）
Read Detail读指令中已经包含“2、单点测量”中所有字段数据的读取。

2.4	实时数据面板 ★通过Read Detail读取
	流速（m/s）：3位小数（经过曲线计算后的流速）
	原始流速（m/s）：3位小数未经曲线计算前的流速
	累计流量（m3）：3位小数（仅在自动周期时展示）
	水深（m）：3位小数
	水温（℃）：1位小数
	流量（m³/s）：瞬时流量，3位小数，根据APP本地存储的流量单位来换算显示
	过水面积：（m2）：3位小数
	测量时间：Read detail返回的系统时间，显示格式如2026-04-05 10:30:30
	断面MN：8位字符串
	断面名称:  如：小梅口（预留暂无数据）

3	历史数据  （Read History=n）
核心目标：历史数据列表可查看、可上拉分页加载，可导为CSV格式的历史数据文件，以最旧-最新的数据时间#导出时间戳来命名文件；


4	参数设置与校准
	压力水位计零点校准（空气中）按钮（一键校准）（要弹窗确认提示：请将仪器放置在空气中，进行压力水位计零点校准），通过	Set Pressure来实现；
	曲线系数ABC配置，在曲线ax2+bx+c中 a、b、c可设置,y=ax2+bx+c中y为流速修正后的值，根据此流速（y）进行后续的流量计算。 通过Write Coeff=曲线系数A-曲线系数B-曲线系数C来实现；
	恢复出厂（默认参数）  Set SysInit
	系统时间：对仪器内部系统时间进行校准，默认为手机时间日期，可以手动修改。Write	SysTime=系统正确时间
	流量单位选择：m3/s或L/s，流量单位显示的换算由APP负责（系统存储数据都是m3/s，小数位数都是6位；）
	Write 	Elevation		设置河底高程 单位mm，显示为米保留三位小数；
	Write 	Install		设置安装高度 单位mm，显示为米保留三位小数；
	安装方向：正向、负向，通过Write Direction=1/-1实现；
