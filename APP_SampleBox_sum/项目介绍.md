# APP_SampleBox 项目介绍

## 1. 项目概述

`APP_SampleBox` 是**力合科技（Lihero）**的安卓端水质采样/监测设备配套 App，包名 `com.lh.lhble`。

核心业务：通过 **BLE（低功耗蓝牙）** 连接各类水质采样/监测设备，并提供设备参数配置、数据读取、日志导出、版本升级等功能。

## 2. 模块结构

| 模块 | 作用 |
|---|---|
| `app/` | 主应用模块，包含全部业务页面与逻辑 |
| `wiseKit/` | 自研 BLE 蓝牙 SDK 库（扫描、连接、GATT 封装、通用调试页） |
| `Source/` | 设备协议/需求文档（Markdown） |
| `keyStore` | 应用签名文件 |

## 3. 主应用包结构（`app/src/main/java/com/lh/lhble/`）

| 包 | 说明 |
|---|---|

## 4. 启动流程

```
LaunchActivity（闪屏）
      ↓
LoginActivity（登录）
      ↓
ScanBleActivity（扫描 / 连接设备主页面）
      ↓
按 MAC 地址前缀分派 → 对应设备控制页面
```

## 5. 蓝牙连接主页面入口：`ScanBleActivity`

文件路径：`app/src/main/java/com/lh/lhble/UI/ScanBleActivity.java`

这是"连接各种蓝牙设备"的统一入口，核心功能：

1. **扫描设备**：使用 wiseKit 的 `BluetoothScanManager` 扫描附近 BLE，并按厂商广播前缀过滤力合系设备。
2. **连接设备**：点击列表项调用 `connectBle()` → `WiseBluetoothLe.connectDevice()` 连接（失败最多重试 5 次），开启 `Ble_Config_Receive_Service` / `Ble_Data_Receive_Service` 通知，并协商 MTU = 255。
3. **识别并分派**：按设备 **MAC 地址前缀** 识别设备型号，跳转到对应控制页面。

### 5.1 设备类型识别规则（MAC 前缀分发）

| MAC 前缀 | 设备 | 跳转页面 |
|---|---|---|
| `00` | 灌溉采样器 | `LiherGGCYActivity` |
| `0A` | 全版采样瓶 | `LiherAdvancedBottleActivity` |
| `0B` | 简版采样瓶 | `LiherActivity`（默认） |
| `0C` | 矮盖采样瓶 | `LiherShortBottleActivity` |
| `0D` | 便携式采样箱 | `LiherCYXActivity` |
| `0D:01` | 固定式地下水采样箱 | `LiherDXCYXActivity` |
| `0D:02` | 便携式地下水采样箱 | `LiherDXCYX2Activity` |
| `0D:03` | 井下采样器 | 弹窗选择 `LiherDXCYX3Activity`（老程序）/ `LiherCYX7Activity`（2026 兼容 RTU 程序） |
| `0D:04` | 单瓶采样器 | `LiherCYX4Activity` |
| `0D:05` | 新版便携式采样箱 | `LiherCYX5Activity` |
| `0D:06` | 便携式水质自动采样器 | `LiherCYX6Activity` |
| `0E` | 质控模块 | `LiherZKYActivity` |
| `11` | 运输箱 | `LiherYSXActivity`（需高级权限） |
| `12` | 雷达水位计 | `LiherSWJ1Activity` |
| `15` | RTU 采集器 | `LiherRTUActivity` |
| `16` | LHADCP | `LiherADCPActivity` |

### 5.2 其他能力

- **扫码连接**：支持扫描蓝牙二维码（`RequestCode_Scan_BLE_Name`）和 MAC 码（`RequestCode_Scan_MAC_Address`）快速连接。
- 设备搜索过滤、定位/GPS 权限检查、App 版本升级检测。

## 6. 底层 BLE 协议（`base/Constant.java`）

### 6.1 力合协议（主协议）

UUID 前缀 `6c696865-726f-aabb-eeff-...`（"lihero" 的 ASCII 编码），包含 5 组特征值：

| 特征值 | 用途 |
|---|---|
| `Ble_Config_Receive_Service` | 配置下发 |
| `Ble_Data_Receive_Service` | 数据收发 |
| `Ble_LOG_Receive_Service` | 日志接收 |
| EV 数据特征值 | 事件数据 |
| 其他扩展特征值 | 预留 |

### 6.2 大域科技协议（兼容）

私有协议 UUID `0000fff0-...`（`DY_Ble_Data_Service`），对应页面 `DYBleActivity`。

## 7. wiseKit 蓝牙库

自研 BLE SDK，位于 `wiseKit/src/main/java/com/wise/wisekit/`，主要能力：

- 蓝牙扫描（`BluetoothScanManager`）
- 连接管理（`WiseBluetoothLe`）
- GATT 封装、MTU 协商、通知订阅
- `BluetoothControlActivity`：通用 BLE 调试控制页（任意设备原始指令收发）
